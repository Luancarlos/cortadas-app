Política de Privacidade

Última atualização: 19 de outubro de 2026

Dados coletados

Quando o usuário conecta a conta TikTok, a ferramenta recebe e guarda apenas:

  • o token de acesso e o token de renovação fornecidos pelo TikTok;
  • o nome de exibição da conta (escopo user.info.basic), para mostrar qual conta está conectada.

Nenhum outro dado do TikTok é lido: seguidores, mensagens, vídeos publicados ou dados de terceiros não são acessados.

Como os dados são usados

Os tokens são usados somente para enviar à caixa de entrada do TikTok os vídeos que o próprio usuário escolhe enviar.

Onde os dados ficam

Todos os dados ficam armazenados apenas no computador do usuário. Não existe servidor da Cortadas, e nada é enviado a terceiros além da própria API do TikTok.

Compartilhamento

Os dados não são vendidos, compartilhados nem usados para publicidade.

Como remover

O usuário pode desconectar a conta no painel da ferramenta, o que apaga os tokens e revoga o acesso, ou remover a autorização a qualquer momento nas configurações de segurança do TikTok.

Privacy Policy

Last updated: October 19, 2026

Data collected

When the user connects a TikTok account, the tool receives and stores only:

  • the access token and refresh token issued by TikTok;
  • the account display name (user.info.basic scope), to show which account is connected.

No other TikTok data is read: followers, messages, published videos and third-party data are never accessed.

How data is used

The tokens are used only to upload to the TikTok inbox the videos the user chooses to send.

Where data is stored

All data is stored only on the user's own computer. There is no Cortadas server, and nothing is sent to third parties other than TikTok's own API.

Sharing

Data is not sold, shared or used for advertising.

How to delete

The user can disconnect the account in the tool's dashboard, which deletes the tokens and revokes access, or remove the authorization at any time in TikTok's security settings.
